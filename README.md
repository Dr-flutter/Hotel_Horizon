# Hotel Horizon

Hotel Horizon est une application web moderne pour la gestion d'un hôtel, offrant des fonctionnalités telles que la gestion des chambres, des réservations, des utilisateurs, et bien plus encore.

## Fonctionnalités

- **Gestion des chambres** : Ajouter, modifier, et supprimer des chambres.
- **Gestion des réservations** : Voir les réservations, mettre à jour leur statut, ou les annuler.
- **Gestion des utilisateurs** : Ajouter, modifier, et supprimer des utilisateurs.
- **Interface utilisateur réactive** : Adaptée aux écrans de toutes tailles.
- **Multilingue** : Supporte l'anglais et le français.

## Technologies utilisées

- **Frontend** : React, TailwindCSS, Framer Motion
- **Gestion d'état** : Zustand
- **Internationalisation** : i18next
- **Outils de développement** : Vite, ESLint, TypeScript
